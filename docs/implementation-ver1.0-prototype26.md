# Ver.1.0 試作26 実装メモ

## 今回の目的

13種類の鳥について、speciesや保存レコードを増やさず、現在のなかよしレベルに応じて同じ鳥が少しずつ華やかになる「なかよし進化」を追加した。試作25の鳥SVG、正式名称、speciesId、companionId、取得状態と履歴を維持することを優先した。

## なかよし進化の仕様

進化は能力値や報酬を増やさない表示上の成長である。別speciesへの置換、新しいカード、進化専用companionは作らない。

- stage 1「ちいさなすがた」: bondLevel 1～2
- stage 2「せいちょうしたすがた」: bondLevel 3～4
- stage 3「とくべつなすがた」: bondLevel 5以上

`getCompanionEvolutionStage(companion)`がstageを毎回算出する。stageそのものは保存しない。数値以外、非有限値、1未満のbondLevelはstage 1として扱う。

`getEvolutionProgress(companion)`は現在stage、段階名、次の閾値、残りレベルを図鑑表示用に返す。

## 進化姿の描画方式

`js/companions.js`の試作25の13 species定義は変更していない。`EVOLUTION_DECORATIONS`へstage 2・3の追加SVGだけを定義し、共通`renderCompanion()`が次の順で描画する。

1. stage別の後方装飾
2. 試作25のbody regions、outline、inner lines、face
3. stage別の前方装飾

stage 1では進化装飾グループを出力しないため、試作25の姿を維持する。SVGには表示名と段階名を含むaria-labelを付ける。シルエット表示には進化装飾を付けない。

## bondLevel上昇との連携

`increaseCompanionBond(companion, amount, reason)`を共通処理として追加した。再孵化と料理の既存2経路がこの関数を使う。

- 再孵化: 従来どおりbondLevelを1増加
- 料理: 同じ鳥へ3日分の初回食事を行った時だけ従来どおりbondLevelを1増加

上昇量、食事条件、hatchCount、bondMealProgressの仕様は変更していない。stage境界を越えたかだけを戻り値で通知する。

## 進化演出と既読情報

進化既読は取得済みcompanionレコードの任意項目`lastSeenEvolutionStage`へ保存する。表示stageは保存せずbondLevelから再計算する。

再孵化または料理でstage 1から2、stage 2から3へ進んだ場合、未確認stageとして検出する。進化ダイアログを開く直前に現在stageを既読として保存するため、リロード、閉じる操作、ボタン連打で同じ演出を再表示しない。

ダイアログはニックネームを優先し、未設定時は正式名称を使う。role、aria-live、閉じるボタン、Escape、開始フォーカス、終了時のフォーカス復帰を実装した。`prefers-reduced-motion`では既存の共通CSSにより大きな動きを停止する。

未確認進化が残った場合は、ホームへ「なかよし進化した なかまがいるよ！」を1件だけ表示し、1つのダイアログ内でまとめて確認できる。13回の連続ダイアログは表示しない。

## 既存ユーザーの初回扱い

試作25以前のcompanionには既読情報がない。`ensureCompanions()`で初めて補完する際、その時点のbondLevelから求めたstageを既読値にする。このためアップデート直後から正しい姿を表示しつつ、大量の進化ダイアログを出さない。補完は冪等で、以後の新しい閾値到達だけが未確認になる。

## 各機能との互換性

- ニックネーム: `getCompanionDisplayName()`を維持し、進化演出とSVG aria-labelでも優先
- おきにいり: 内部`isFavorite`とfavorite処理を変更しない
- 孵化: fixed seed、`plannedSpeciesId`、未取得優先、新規カード、再孵化のカード重複防止を維持
- 図鑑: 現在stage、次の段階、残りレベルを文字で表示
- ホーム・なかまのようす: 現在の段階名を短く表示
- キッチン: 食事対象カードと食後表示に現在stageを反映
- おでかけ: 選択、出発中、帰宅表示で共通レンダラーを使用し、tripデータは変更しない
- とりのおうち: 既存の13羽固定配置、家具15種類、配置枠8種類、おでかけ中の非表示を維持
- JSON: companion任意項目として既読値を出力・復元し、stageは復元後に再計算

## 不正データ対応

文字列、null、NaN、負数、オブジェクトのbondLevelはstage判定でstage 1となる。保存データ正規化では不正bondLevelを0へ補正する。不正な既読値は現在stageへ補正し、現在stageより先の既読値は現在stageまで戻す。有効なnickname、favorite、hatchCount、mealCount、lastFedAtは維持する。
